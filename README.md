# Presentación HTML

Proyecto de presentación HTML con contenido visual y assets locales.

## Estructura

- `02_SLIDES_HTML/` contiene la presentación principal.
- `PAC7.0-WSEF_deck_v29.html` es el archivo principal de la vista de la presentación.
- `_DOCS/` incluye documentación del proyecto.

## Cómo abrirlo

Abre el archivo `PAC7.0-WSEF_deck_v29.html` en el navegador, o sirve la carpeta con un servidor local.
